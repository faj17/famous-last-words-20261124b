The funniest last words a phone says as its battery hits 1 percent (109 characters):

> I survived 400 notifications, 12 alarms and one very long video, and this is how it ends: mid-sentence, like—

The setup is the phone boasting about everything it survived. The punch is the line itself dying: it cuts off in the middle of the word "like", so the phone does not get to finish its own last words. It speaks in the phone's own first-person voice about its own dying battery, the punch lands in the final beat, and it uses none of the stock moves — no will reading, no goodbye to the charger, no pun on 1 percent.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
